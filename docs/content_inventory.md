# Quality assurance
- Validasi otomatis mengecek struktur soal, distribusi, kode/pertanyaan duplikat, dan jumlah opsi.
- Soal dikembangkan sebagai latihan edukatif dari topik materi pengguna, bukan pemindaian verbatim.
- Label easy/medium/hard adalah estimasi awal; review pengajar dan uji peserta diperlukan untuk kalibrasi kesulitan.
- Pengujian aplikasi lengkap dengan PostgreSQL dan browser perlu dilakukan pada server target.
