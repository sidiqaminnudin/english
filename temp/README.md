# EnglishLab Tenses + Dua Ujian — Paket Dokumentasi

Isi:
- `EnglishLab_Tenses_Quick_Reference_and_Exam_Map.pdf` — lembar ringkasan siap cetak.
- `tenses_quick_reference.md` — materi lengkap siap dipakai untuk halaman LMS.
- `two_exam_blueprint.md` — rancangan dua ujian, distribusi soal dan aturan koreksi AI.
- `AGENT_VSCODE_PROMPT.md` — prompt integrasi untuk agent VS Code.

Tidak ada perubahan otomatis pada kode aplikasi/database dengan mengunduh paket ini. Agent VS Code tetap harus mengintegrasikan fitur dan mengetes pada repo aktual.

**Catatan:** ringkasan mencakup 7 tense yang terdapat dalam kumpulan materi yang sudah dikirim; modal verbs dan passive voice dapat digunakan sebagai kategori pelengkap. Simple Present dasar muncul dalam cakupan Ujian 1 karena termasuk materi sebelum Giving Directions, sedangkan dalam Ujian 2 diuji dalam keterampilan menulis/menentukan tense.
